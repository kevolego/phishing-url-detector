What this actually checks for

Before scoring, the link is decoded and unpacked the same way a browser would read it — so tricks meant to hide the real destination get caught:

  • Hidden host behind @ — paypal.com@evil.net looks like PayPal but actually goes to evil.net
  • Raw IP address instead of a real domain name
  • Lookalike characters — domains using Cyrillic or other scripts to mimic Latin letters
  • Percent/hex encoding hiding the real text
  • Typosquatting — close misspellings of big brand names
  • URL shorteners, risky top-level domains, and excessive subdomains

Each check adds points toward a 0–100 score with a plain-English reason — never a black-box guess.

Heuristic tool for educational and defensive use. A low score isn't a guarantee a link is safe — when in doubt, don't enter credentials, and verify through an official channel.
